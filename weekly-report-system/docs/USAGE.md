# 사용 가이드 — SW Solution Part 1 주간보고 시스템

## 화면 구성

| URL | 화면 | 용도 |
|-----|------|------|
| `/` | → 주간 입력 리다이렉트 | |
| `/register` | 과제 등록 | 신규 과제 최초 1회 등록 |
| `/weekly` | 주간 입력 | 매주 보고 내용 입력 |
| `/query` | 조회 대시보드 | 3축 조회 + 산출물 다운로드 |

---

## 1. 신규 과제 등록 `/register`

**최초 1회만 수행. 이미 등록된 과제는 재등록 불필요.**

1. **과제 유형** 선택 → 필드 자동 전환
   - `device` (양산): 플랫폼 + DVR / PVR / PRA / SRA 계획일
   - `advance` (선행): 배경/목표 + EA / ER1 / ER2 / CA 계획일
   - `review` (검토): 배경/목표만 (마일스톤 없음)
2. **과제명** 입력
3. **담당자** 선택 (드롭다운, 자유입력 불가)
4. **등록 주차** 입력 (예: `2026-W24`)
5. **등록** 버튼 클릭 → 완료 화면에서 생성된 과제 ID / 마일스톤 확인

---

## 2. 주간 보고 입력 `/weekly`

**매주 1회 입력.**

### 입력 순서

1. **파트원** 선택 (드롭다운)
2. **과제** 선택 → 해당 TG의 과제 목록 자동 로드
3. **주차** 확인 (자동으로 현재 주차 입력됨, 수정 가능 예: `2026-W23`)
4. **좌우 분할 화면** 확인
   - 왼쪽: 전주 내용 (읽기 전용)
   - 오른쪽: 금주 입력 칸
5. 마일스톤별 행에 **진행 / 일정 / Risk** 입력
   - 텍스트 입력 후 500ms 정지 → **delta 미리보기** 자동 표시 (변경 부분 파란색)
6. **지연사유** (조건부 필수)
   - 마일스톤 상태가 `risk` 이거나 계획일이 지난 경우 반드시 입력
   - 없으면 저장 불가 (422 오류)
7. **이미지 첨부** (선택, 복수 파일 가능, 파일명 영문만 허용)
8. **상태** 선택: `完` / `進` / `이슈`
9. **저장** 클릭

### 주의사항

- 진행 / 일정 / Risk 는 **필수**. 빈칸 저장 불가
- 파일명에 **한글 포함 불가** (예: `보고서.jpg` → 오류)
- 동일 주차에 재저장 시 **덮어쓰기** 처리

## 3. 조회 대시보드 `/query`

### 3축 조회

| 탭 | 조회 기준 | 예시 |
|----|----------|------|
| 파트원별 | 특정 파트원의 기간별 전체 활동 | M01 / 2026-W01 ~ 2026-W52 |
| 과제별 | 특정 과제의 주차별 진행 이력 | P01 / 전체 기간 |
| 태그별 | 특정 기술 태그 관련 항목 조회 | SoundBooster |

### 마일스톤 현황

대시보드 상단 차트: 완료 / 진행 / 위험 건수 (Chart.js 실 파일 반입 후 활성화)

---

## 4. 산출물 다운로드

조회 대시보드 하단 **산출물 다운로드** 섹션:

### 주간보고 DOC

- **주차 입력** (예: `2026-W23`) → **다운로드**
- 생성 내용:
  - TG 순서: Audio Solution → Audio SW → Wireless Audio
  - 상단: 마일스톤 현황표 (위험 항목 빨간색)
  - 변경된 텍스트 **파란색(RGB 0,0,255)** 표시
  - 이미지 첨부 임베드

### MBO XLS

- **연도 입력** (예: `2026`) → **다운로드**
- 내용: MBO 목표 / 현재 달성 / 달성률 수식

### 피드백 XLS

- 전체 기간 보고 항목 집계 (완료/진행/이슈 구분)

### 평가 XLS

- **연도** 입력 → 파트원별 연간 완료율 수식

## 5. 백업

### 수동 백업
```bat
backup.bat
```
→ `backup\backup_YYYYMMDD.zip` 생성 (DB + 이미지 포함)

### 자동 백업 (Windows 작업 스케줄러)
1. 작업 스케줄러 → **새 작업 만들기**
2. 트리거: 매일 오전 02:00
3. 동작:
   ```
   프로그램: C:\Python311\python.exe
   인수: backup\backup.py
   시작 위치: C:\weekly-report-system
   ```

## 7. 자주 묻는 질문

**Q. 저장이 안 됩니다 (422 오류)**
- 진행 / 일정 / Risk 모두 입력했는지 확인
- 지연 상황(risk 상태 또는 계획일 경과)이면 지연사유 입력 필수

**Q. 이미지 파일명 오류가 납니다**
- 파일명을 영문으로 변경하세요 (예: `보고서.jpg` → `report.jpg`)

**Q. 서버가 응답하지 않습니다**
- 서버 PC에서 `start.bat` 실행 여부 확인
- 포트 5000 방화벽 허용 여부 확인

**Q. 차트(그래프)가 보이지 않습니다**
- `static\vendor\chart.min.js` 파일을 실제 Chart.js로 교체 필요
- `docs\INSTALL.md` 5번 항목 참조

**Q. 신규 과제를 중간에 추가하고 싶습니다**
- `/register` 에서 언제든 추가 등록 가능

**Q. 주간보고를 수정하고 싶습니다**
- 동일 파트원 / 과제 / 주차로 다시 저장하면 덮어쓰기됩니다
